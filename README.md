🍽️ Food Feedback Analyzer

A web app that analyzes customer food reviews using sentiment analysis — instantly showing sentiment, score, and main topic, while saving results to a searchable feedback database.

✨ Features
📝 Paste any customer review and analyze it instantly
😊 Detects sentiment — Positive, Neutral, or Negative
⭐ Gives a score out of 5
🏷️ Identifies the main topic (e.g. Experience, Delivery, Food Quality)
💾 Saves every result to a feedback database
🔍 Searchable record of all past reviews
